# Изменения Windows-сборки

## ZeTer OS 4.0.100 — Windows x64, 27 октября 2026

- При подготовке выпуска восстановлена совместимость сборщика с короткими Windows-путями; проверка реального выхода файлов за пределы проекта сохранена.

- Мобильный интерфейс: полноэкранные окна и крупные области нажатия, компактные панели Проводника, меню ярлыков, выбор рабочего стола из шапки и список приложений при переполнении панели задач.
- В меню действий материалов видно полное имя; дополнительные команды заметок на телефоне доступны через «Ещё». Настольные команды сохранены.
- Обновлены Google Drive: обмен изменёнными файлами, восстановление облачного корня и уведомления о входящих изменениях. Работа с реальными устройствами и OAuth проверяется отдельно.
- Все предыдущие возможности календаря, задач, контактов, учёта времени, документов и резервного копирования входят в эту версию. Подробности — в CHANGELOG.
- Перед обновлением создайте ZIP-бэкап. Скачайте `ZeTer-OS-4.0.100-Windows-x64.zip`, распакуйте целиком в новую папку и запускайте `ZeTer-OS.exe`; Python пользователю не нужен. Рядом публикуется SHA-256 архива.
- Предварительная сборка без цифровой подписи. CI выполняет проверку исходников и packaged self-test; ручной Windows GUI, настоящие устройства и перенос пользовательских данных остаются отдельными проверками.

## ZeTer OS 4.0.64 — Windows x64, 19 октября 2026

- В ходе подготовки релиза исправлено ложное определение выхода за пределы проекта при проверке Windows-путей `RUNNER~1`/`runneradmin`; защита от настоящего выхода за пределы папки сохранена. Добавлено правило `.gitattributes` для сохранения точных байтов веб-комплекта при checkout на Windows; контрольный manifest 4.0.64 остаётся согласованным. Добавлен регрессионный smoke-тест.
- Обновлён интерфейс рабочего стола и Проводника: новые представления, сортировка, размеры элементов, поведение окон и закреплённых приложений.
- Переработаны меню «Пуск», каталог приложений и мастер первого запуска; обновлены настройки с поиском, разделами, сочетаниями клавиш и параметрами оформления.
- Расширено приложение задач: проекты, категории, доска, список и обзор со сроками, статистикой и настройками каждого проекта.
- Обновлён Центр безопасности: проверка и восстановление резервных копий, управление хранилищем и защита данных; добавлены проверки архивов и сценарии отказов.
- Улучшены просмотр системных показателей и документация; добавлены регрессионные тесты сохранения, интерфейса и обновления веб-кэша.
- Для веб-версии введён проверяемый комплект `app/web-release.json`, чтобы обычная загрузка/F5 получала согласованные ресурсы без потери пользовательских данных. Новый адрес онлайн-версии: https://dkl.do.am/zeteros/index.html.
- Исходный код, упаковка и Windows x64 ZIP проверяются в GitHub Actions; ручная проверка установленного интерфейса Windows/WebView2 остаётся отдельной задачей. Полная история: [CHANGELOG.md](CHANGELOG.md).

### Запуск Windows x64

Скачайте ZIP и соответствующий файл SHA-256 из Assets выпуска, сверьте контрольную сумму, распакуйте каталог целиком и запустите `ZeTer-OS.exe`. Для графического интерфейса требуется Microsoft Edge WebView2 Runtime. EXE не подписан цифровой подписью издателя.

## ZeTer OS 4.0.16 — подготовленные исходники, 14 октября 2026

- Проверка обновлений через фиксированный файл версии на GitHub Pages: при запуске, каждые шесть часов и по ручной кнопке. Программа не обращается к GitHub REST API.
- ZIP скачивается напрямую из Releases после нажатия «Обновить»; обязательны проверки версии, размера, SHA-256 и состава пакета. Сохранение данных и восстановление при отказе установки сохранены.
- CI публикует файл версии только после проверки публичного скачивания готового ZIP. Старые пакеты не перезаписываются; повтор старого запуска не может понизить версию на Pages.
- Для канала требуется Settings репозитория → Pages → Source → GitHub Actions. Полная инструкция: [docs/UPDATES.md](docs/UPDATES.md). Старым EXE для перехода нужна новая полная сборка.
- Локальные синтетические проверки не подтверждают live Pages/CI/CDN или новую Windows EXE. Сборку и публикацию этой версии выполняют отдельно.

## Упаковка и публикация

- Готовая desktop-сборка ZeTer OS теперь публикуется как постоянный GitHub Release.
- Portable ZIP содержит `ZeTer-OS.exe`, встроенный Python/pywebview runtime и полный web-слой приложения.
- Перед публикацией GitHub Actions запускает compile, полную проектную проверку, сборку native EXE и packaged `--self-test`.
- В релиз добавлен отдельный SHA-256 для проверки целостности portable-архива.
- README теперь прямо указывает, где скачать готовую Windows-версию и что архив нужно распаковывать целиком.

## Проверка

CI подтверждает корректность packaged runtime и наличие обязательных файлов `app/index.html` и `app/js/core/version.js`. Реальные desktop-сценарии с пользовательскими данными, файловыми диалогами и установленным WebView2 требуют проверки на целевой Windows-машине.
