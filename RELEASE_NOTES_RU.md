# Изменения Windows-сборки

## ZeTer OS 4.0.11 — 14 октября 2026

- Добавлен поиск обновлений в GitHub Releases из Windows x64-сборки, в том числе автоматическая проверка новых версий и уведомления в интерфейсе.
- Предусмотрены безопасная загрузка обновления с проверкой SHA-256 и манифеста, резервная копия, откат после ошибки и сохранение пользовательской папки `data`.
- Добавлены окно «О ZeTer OS» с версией, контактами и ссылками, отдельная инструкция по ручному обновлению, приложения «Промпты» и «Подсчёты».
- Улучшено перемещение карточек в «Подсчётах», интерфейс верхней панели и синхронизация документации, справки, файлов сборки и PWA-кэша.
- Для Windows x64 этот выпуск предоставляет `ZeTer-OS-4.0.11-Windows-x64.zip` и `ZeTer-OS-4.0.11-Windows-x64.sha256.txt`. ZIP содержит `ZeTer-OS.exe`, отдельный `ZeTer-OS-Updater.exe`, встроенный Python runtime, приложение и `zeter-update.json`.
- Подробная история изменений и результаты тестирования: [CHANGELOG.md](CHANGELOG.md).

### Как установить

Скачайте `ZeTer-OS-4.0.11-Windows-x64.zip` из Assets этого выпуска, при необходимости проверьте SHA-256 по одноимённому `.sha256.txt`. **Распакуйте весь ZIP в отдельную папку** и запустите `ZeTer-OS.exe`: не извлекайте один EXE отдельно. Весь каталог приложения нужен для работы.

Для ручного обновления старой установки сначала создайте резервную копию. Не удаляйте старую папку и сохранённые пользовательские данные (`data/`), пока не убедитесь, что новая версия запускается. Автообновление из поддерживаемой сборки использует проверку SHA-256, manifest и откат при ошибке.

### Проверка и ограничения

GitHub Actions собирает Windows x64 ONEDIR, проверяет Python/Node-код, запускает packaged `--self-test`, проверяет обязательные web-assets и публикует ZIP только после успешной сборки. Полноценное ручное GUI-тестирование на пользовательской Windows-машине не заменяется CI. Исполняемые файлы не имеют подписи Authenticode; для графического запуска требуется Microsoft Edge WebView2 Runtime.


## ZeTer OS 4.0.8 — предыдущая опубликованная Windows x64-сборка

14 октября 2026 года

## Что нового по сравнению с 4.0.1

- **Промпты:** отдельная библиотека промптов на каждом рабочем столе: проекты, категории, поиск, избранное и точное копирование текста. Сохранение, импорт, экспорт, резервные копии и операции удаления учитывают данные библиотеки.
- **Подсчёты:** 10 бизнес-калькуляторов, в том числе маржа, наценка, ROI, CAC/LTV, безубыточность, скидки и план продаж; карточки поддерживают скрытие/возврат, изменение размеров, перетаскивание и сохранение для каждого рабочего стола.
- **Надёжность сохранения и Windows-копий:** улучшены staged-сохранение, поведение при отказах записи, сравнение содержимого файлов и DOCX, восстановление и диагностика операций.
- **Интерфейс и управление карточками:** исправлены названия ярлыков и точная позиция при перетаскивании карточек; справка, тесты и PWA-кэш обновлены.
- **Версия:** `4.0.8`. Подробности и история промежуточных версий — [CHANGELOG.md](CHANGELOG.md).

## Загрузка и запуск

Скачайте файл `ZeTer-OS-Windows-x64.zip` из раздела Assets этого выпуска. Распакуйте ZIP целиком, затем откройте `ZeTer-OS.exe` внутри папки `ZeTer-OS`. Не извлекайте один EXE отдельно: для запуска нужны остальные файлы папки.

Сборка содержит Python runtime, pywebview и web-слой приложения. В CI установка WebView2 на компьютере пользователя не проверяется: если при запуске отсутствует необходимый Microsoft Edge WebView2 Runtime, установите его официальным установщиком Microsoft.

Файл `ZeTer-OS-Windows-x64.sha256.txt` содержит контрольную сумму SHA-256 portable ZIP.

## Контроль качества

В исходном CHANGELOG 4.0.8 отражён strict-check: 129 OK, 0 warnings, 0 failures. Workflow этого выпуска отдельно выполняет компиляцию Python, строгую проверку проекта, native ONEDIR-сборку через PyInstaller, проверку обязательных web-assets и `ZeTer-OS.exe --self-test` перед публикацией.

**Ограничение:** packaged self-test не заменяет ручное тестирование GUI, WebView2, файловых диалогов и пользовательских сценариев на реальной Windows-машине. Готовый EXE не подписан цифровой подписью издателя.
