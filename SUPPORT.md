# Поддержка и сообщения об ошибках

Для проблем ZeTer OS укажите, где они воспроизводятся: в desktop-версии через `pywebview`, в веб-версии или в обеих.

Полезно приложить:

- версию/ревизию проекта;
- Windows и версию Python для desktop-сценария либо браузер для web-сценария;
- конкретный модуль: заметки, задачи, календарь, файлы, таблицы и т. д.;
- точные шаги воспроизведения;
- ожидаемый и фактический результат;
- безопасный фрагмент диагностического лога.

## Пользовательские данные

ZeTer OS хранит локальное рабочее состояние. Не публикуйте без проверки содержимое `data/`, резервные копии, экспортированные документы, заметки, задачи или другие личные данные.

Перед экспериментами с восстановлением или переносом состояния сделайте резервную копию важных данных.

Для обычных воспроизводимых ошибок используйте GitHub Issues. Потенциальные уязвимости сообщайте по правилам из [`SECURITY.md`](SECURITY.md).
