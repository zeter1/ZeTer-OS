# Небольшая мобильная проходка

Принято пользователем: три улучшения из предложения в чате — выбор стола из шапки,
название материала в меню действий, дополнительные команды заметки под «Ещё».
Основные команды заметки: «Новый» и «Папка». Формат данных и сохранение не меняются.

## Реализация и проверки

- [x] Использовать существующее контекстное меню для списка столов; вызывать прежний
  switchVirtualDesktop. Активный стол отмечен, длинные имена переносятся.
- [x] Добавить необязательный заголовок контекстного меню через textContent;
  передавать имя материала с рабочего стола и из Проводника.
- [x] В мобильной шапке редактора скрыть дополнительные кнопки и показать «Ещё»;
  меню вызывает те же обработчики, учитывает недоступные команды Word.
- [x] Проверить Escape/возврат фокуса, закрытие снаружи, 320/390/430 и поворот,
  desktop-регрессию, текст заметки → смена стола → возврат → reload.
- [x] Обновить справку, README, владельцев, версию, PWA-кэш и web-release штатным
  генератором; выполнить профильные smoke, browser acceptance и strict-check.

Владельцы: shell-ui-utils, context-menu-ui-utils, editor-ui-utils, explorer-ui-utils;
app.js остаётся адаптером. CSS — 95-mobile.css. Отдельный browser smoke использует
public preview app/, новый context, synthetic state; без native API, внешней сети,
service worker и пользовательских data/. Изменения пишет основной агент.

Общий popup выбран вместо нового независимого overlay: он уже поддерживает мобильную
нижнюю панель и закрытие снаружи. Desktop сохраняет все кнопки редактора на виду.
Публикация, EXE и установленная PWA не входят в эту проходку.

Приёмка: 67 общих + 11 профильных browser-сценариев; 0 JS errors. Independent
static/VM review PASS; strict 175 OK / 0 warnings / 0 failures. Артефакты и первые
отказы среды: work/mobile-polish-qa/. Тест переключает стол после подтверждённого
сохранения; pending autosave и настоящий телефон/PWA/EXE остаются NOT_VERIFIED.
