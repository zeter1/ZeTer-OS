# Логотип ZeTer OS

Единый знак — две соединённые синие плоскости с просветом в форме Z: тёмная задняя и яркая сине-фиолетовая передняя. Надпись сохраняет точное написание `ZeTer OS`.

## Источник и производные

Исходник геометрии, градиентов и цвета подложки — [`app/assets/icons/zeter-mark.svg`](../app/assets/icons/zeter-mark.svg). Прозрачный знак предназначен для светлого фона; на тёмном используют иконку со светлой подложкой. Все производные создаёт [`tools/build_brand_assets.ps1`](../tools/build_brand_assets.ps1), без дополнительных пакетов, средствами Windows System.Drawing:

```powershell
.\tools\build_brand_assets.ps1
.\tools\build_brand_assets.ps1 -Check
```

Генератор читает только исходный SVG и записывает семь перечисленных ниже файлов в `app/assets/icons/`. `-Check` сравнивает результат с исходником без записи. SVG использует простые polygon и linearGradient с абсолютными координатами; при расширении этих конструкций сначала обновляют генератор.

| Файл | Назначение |
|---|---|
| `zeter-logo.svg` | Общая иконка на светлой скруглённой плитке: загрузка, кнопка Пуск, экран паузы, О ZeTer OS, favicon и README |
| `zeter-icon-32.png` | Маленькая PNG-иконка для внешнего использования |
| `zeter-icon-180.png` | Apple touch icon |
| `zeter-icon-192.png`, `zeter-icon-512.png` | Обычные PWA-иконки |
| `zeter-icon-maskable-512.png` | Непрозрачная квадратная PWA-иконка; весь знак внутри центральной безопасной окружности радиусом 40% стороны |
| `zeter-icon.ico` | Иконка окна Python и будущего EXE; PNG-кадры 16/24/32/48/64/128/256 px |

Растровые иконки, ICO и `zeter-logo.svg` вручную не меняют. Светлая плитка `#f7f5ed` сохраняет контраст тёмной плоскости в обеих темах интерфейса. Цвет подложки задаётся атрибутом `data-icon-background` исходного SVG в формате `#RRGGBB` и одинаково применяется к SVG, PNG и ICO; отсутствие или неверный формат останавливает генератор. В маленьких иконках используют только знак, без текста.

## Подключение

`app/index.html` подключает favicon и touch icon; `app/manifest.json` разделяет обычные и maskable-иконки. `app/service-worker.js` кэширует весь комплект. Версию и кэш обновляют по [правилам версий](../README.md#версии-и-история-изменений).

`run_zeter_os.py` передаёт абсолютный путь ICO через `webview.start(icon=...)`; установленный Windows backend pywebview читает его при создании окна. `build_exe.bat` использует тот же ICO через `--icon`, а `--add-data "app;app"` включает комплект в дистрибутив. Для изменения значка существующего EXE требуется новая сборка; изменение исходников не заменяет уже установленное приложение и не публикует веб-версию.

Проверки и ручная приёмка — в [TESTING.md](TESTING.md#логотип-и-иконки).
