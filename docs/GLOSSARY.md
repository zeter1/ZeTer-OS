# Термины ZeTer OS

Этот словарь фиксирует термины, которые легко перепутать при работе с несколькими рабочими столами, проводником и хранилищами.

| Термин | Значение |
|---|---|
| **Core-модуль** | Файл в `app/js/core/`, отвечающий за одну область и экспортирующий один `window.ZETER_*` |
| **Публичный глобал** | Объект `window.ZETER_*`, через который `app.js` или другой, загруженный позже модуль получает функции |
| **Владелец** | Core- или CSS-модуль, в котором сосредоточена основная реализация конкретного поведения |
| **Composition root** | `app.js` как верхний слой связывания текущего state, DOM, controllers, сохранения и native API |
| **Тонкий адаптер** | Небольшая функция в `app.js`, передающая core-модулю текущий `state`, callbacks, DOM или runtime-зависимости |
| **Controller** | Объект, управляющий законченным runtime-сценарием через явные данные, зависимости и callbacks |
| **Action flow** | Проверяемая цепочка от пользовательского действия и payload до изменения модели, DOM, сохранения или ошибки |
| **Smoke-test** | Быстрая сценарная проверка публичного контракта с минимальными заглушками без запуска всего GUI |
| **Strict-check** | `.\check_project.cmd --strict-node --no-pause`; полная структурная, синтаксическая и smoke-проверка проекта |
| **CSS cascade** | Правила выбора итогового CSS-свойства с учётом порядка файлов, specificity и source order |
| **Override-слой** | Поздний CSS-файл для осознанных межкомпонентных переопределений, а не место для любой новой правки |
| **Selector scope** | Ограничение CSS-правила корневым классом компонента, предотвращающее влияние на соседний интерфейс |
| **State** | Полное изменяемое пользовательское состояние интерфейса |
| **State record** | Обёртка с версией, временем, размером, режимом хранения и вложенным `state` |
| **Desktop** | Запись рабочего стола из `state.desktops[]` с ID, профилем и собственным `data` |
| **Desktop root** | ID корня файловой области конкретного рабочего стола; основной исторический root — `desktop` |
| **Explorer root** | Корень отдельного пространства проводника внутри рабочего стола; может отличаться от desktop root |
| **Workspace** | Набор данных рабочего стола: настройки, задачи, события, уведомления, окна, стикеры и explorer state |
| **FS item** | Объект из `state.fs`, представляющий файл, папку, заметку, ярлык приложения, изображение или другой item |
| **App shortcut** | FS item типа приложения, ссылающийся на запись каталога через `appId` |
| **Action history** | Ограниченная история действий, используемая для отмены операций |
| **Trash** | Логическое состояние удалённых items до восстановления или окончательной очистки |
| **Native-режим** | Запуск через Python/pywebview с сохранением в папку `data/` |
| **Browser-режим** | Запуск веб-интерфейса без Python bridge с основным состоянием в IndexedDB |
| **Canonical state** | Основной источник полного восстановления: JSON-файл в native-режиме или IndexedDB в browser-режиме |
| **Windows-читаемая копия** | Производная папка `data/Рабочие столы/`, пересоздаваемая из canonical state |
| **Backup** | Резервная JSON/ZIP-копия состояния или автоматическая копия в `data/backups/` |
| **Restore point** | Ограниченный снимок состояния в `data/restore-points.json` или соответствующем browser-хранилище |
| **PWA cache** | Offline-кэш browser-режима; имя должно соответствовать версии ZeTer OS |
| **Migration** | Совместимое преобразование загруженного старого state к текущим defaults и normalizers |
| **Normalizer** | Функция, добавляющая безопасные defaults и исправляющая форму данных без потери пользовательского содержимого |
