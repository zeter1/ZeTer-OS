# ZeTer OS — Python/Desktop-версия с папкой данных

Эта версия запускается через `run_zeter_os.py` или `start_zeter_os.cmd`.
Интерфейс остаётся HTML/CSS/JS, но он открывается в отдельном Python-окне через `pywebview`, а данные сохраняются в папку `data` рядом с программой.

## Как запустить на Windows

1. Распакуй архив в обычную папку, например:
   `D:\Programs\PY ZeTer OS`
2. Запусти:
   `start_zeter_os.cmd`

Ручной запуск из CMD/PowerShell в папке проекта:

```bat
py -3 -m pip install -r requirements.txt
py -3 run_zeter_os.py
```

## Автозапуск вместе с Windows

Открой `Настройки → Запуск и восстановление окон` и включи «Запускать ZeTer OS вместе с Windows». Настройка действует для текущего пользователя Windows, общая для всех рабочих столов ZeTer OS и не требует прав администратора.

Если папку программы перенесли, сначала запусти ZeTer OS вручную из нового расположения, затем включи галочку снова — системный путь автозапуска обновится. При переносе одной папки `data` на другой компьютер автозапуск не переносится, потому что это настройка самой Windows.

## Как создать чистый ZIP-релиз

Сборщик предназначен для передачи самой программы другому человеку. Это не резервная копия пользовательских данных и не функция «Центра безопасности».

1. Запусти двойным щелчком `build_release.cmd`.
2. Дождись сообщения `Release build finished successfully`.
3. Забери готовый архив `dist/ZeTer_OS_<версия>_portable.zip`.

Сборщик можно запускать сколько угодно раз. Он каждый раз заново создаёт ZIP по текущему исходному коду, проверяет его целостность, распаковывает тестовую копию в путь с пробелами и кириллицей и только после этого заменяет предыдущий архив той же версии. В окне также показывается SHA-256 архива.

В релиз входят только `app/`, `run_zeter_os.py`, `start_zeter_os.cmd`, `requirements.txt` и эта инструкция. Не включаются `data/`, логи, `.git`, `.codex`, `.agents`, инструменты разработки, тестовые и временные файлы. Поэтому передавать ZIP безопасно, но для переноса своих рабочих столов и файлов отдельно копируй всю папку `data`, как описано ниже.

## Где хранятся данные

Папку выбирать не нужно. ZeTer OS сама создаёт и использует папку `data` рядом с программой:

```text
PY ZeTer OS/
├─ run_zeter_os.py
├─ start_zeter_os.cmd
├─ app/
└─ data/
   ├─ zeter-os-state.json
   ├─ restore-points.json
   ├─ backups/
   ├─ logs/
   ├─ Файлы ZeTer OS/
   ├─ Оформление объектов/
   ├─ README_ДАННЫЕ_WINDOWS.txt
   └─ Рабочие столы/
```

## Главное состояние для восстановления

Полное состояние ZeTer OS сохраняется здесь:

```text
data/zeter-os-state.json
```

Именно этот файл нужен самой ZeTer OS для полного восстановления: рабочие столы, окна, настройки, папки, задачи, календарь, изображения и служебные данные.

## Windows-копии данных

Дополнительно при каждом сохранении ZeTer OS автоматически создаёт обычные файлы, которые можно открыть в Windows:

```text
data/Рабочие столы/
├─ 01 - Основной/
│  ├─ Заметки/
│  ├─ Задачи/
│  ├─ Календарь/
│  ├─ Фотографии/
│  ├─ Изображения/
│  ├─ Таблицы/
│  ├─ Файлы/
│  ├─ Уведомления/
│  └─ Настройки/
└─ 02 - Другой рабочий стол/
   └─ ...
```

Форматы:

```text
Заметки      → один .docx-файл на заметку; изображения встроены внутрь DOCX
Задачи       → .docx + общий .csv для списка
Календарь    → .docx, .csv, .ics
Фотографии   → .png, .jpg, .webp, .gif, .bmp
Изображения  → обои, иконки и другие отдельные картинки
Таблицы      → .csv
Файлы        → исходные .txt/.md/.json/.html/.css/.js и т.п.
Настройки    → .json + документ профиля рабочего стола
```

Важно: папка `data/Рабочие столы` — это автосозданная Windows-копия. Её удобно открывать, просматривать и копировать. Но редактировать данные лучше внутри ZeTer OS, потому что при следующем автосохранении эта копия синхронизируется заново. Если ты удаляешь элемент в ZeTer OS, он исчезает из текущего состояния и Windows-копии при сохранении. Его физические данные могут временно сохраняться, пока на них ссылается точка восстановления или JSON-backup.

## Что изменено в этой сборке

- Добавлен автоматический экспорт данных в Windows-форматы.
- У каждого рабочего стола появилась своя папка внутри `data/Рабочие столы`.
- Заметки сохраняются одним `.docx`-файлом с встроенными изображениями; дубли `.doc` и `.txt` больше не создаются.
- Календарь сохраняется как `.docx`, `.csv` и `.ics`.
- Фото, обои и иконки сохраняются отдельными файлами изображений. Изображения внутри заметок встраиваются в DOCX-файл заметки без отдельного дубля.
- Свои значки папок/ярлыков и фоны папок сохраняются в `data/Оформление объектов` и переносятся вместе со всей папкой `data`.
- Таблицы сохраняются в `.csv`.
- В Центре безопасности добавлена кнопка «Открыть Windows-папки».
- Кнопка «Папка данных» открывает `data`.
- В Настройках доступен общий для всех рабочих столов автозапуск ZeTer OS после входа в Windows.
- В Python-режиме отключена регистрация PWA/service worker.
- Удалённые элементы больше не экспортируются в Windows-папки и перед сохранением очищаются из состояния, чтобы не занимать место впустую.

## Важные нюансы

- Не запускай `app/index.html` двойным кликом, если хочешь хранение в папке `data`. При таком запуске данные снова будут браузерными.
- Запускай именно `run_zeter_os.py`, `start_zeter_os.cmd` или `start_zeter_os.bat`.
- Не клади программу в `C:\Program Files`, потому что Windows может запретить запись рядом с программой.
- Лучше использовать обычную папку: `D:\Programs\PY ZeTer OS`, `C:\Users\Имя\Desktop\PY ZeTer OS` или похожую.
- Чтобы перенести данные на другой компьютер, сначала полностью закрой ZeTer OS, затем скопируй всю папку `data` без выборочного удаления файлов в другую установленную копию ZeTer OS. Если в ней уже есть свои данные, сначала сохрани её старую папку `data` отдельно.
- После переноса запусти ZeTer OS через `start_zeter_os.cmd` или `run_zeter_os.py`, открой несколько заметок/задач/файлов и выполни «Сохранить сейчас». Явно созданные ярлыки на внешние Windows-пути могут потребовать исправления, если на новом компьютере таких путей нет.

## Что остаётся вебовым

Интерфейс технологически остаётся веб-интерфейсом: HTML/CSS/JS внутри окна приложения.
Но данные при запуске через Python сохраняются не в Chrome/Edge/Firefox, а в папке `data` рядом с программой.

## Исправления Windows-копий

- Одна заметка в `data/Рабочие столы/.../Заметки/` теперь создаёт один файл `.docx`, а не `.doc` + `.docx` + `.txt`.
- Изображения заметки встроены внутрь `.docx`; отдельные дубли картинок из заметок не создаются.
- При удалении элементов ZeTer OS очищает их из текущего состояния и Windows-копий, но не повреждает уже существующие точки восстановления и JSON-backups.
- Количество авто-бэкапов ограничено до 12.
